Startup · Started Feb 2026 · Early development

Kshna

Python on the chart, Rust under the hood.

Kshna is a chart-first workspace for writing indicators and strategies in Python instead of Pine Script and backtesting them on a Rust engine. Every trade is marked on its candle, next to the metrics, the trade list and the equity curve.

It stands on two of my own libraries. v1charts draws the chart, and strategies can call the indicators built into v1indicators, such as SuperTrend.

kshna.techNot open for public sign-up yet. To ask for early access, email contact@kshna.tech.
  1. 01Python authoringStrategy and indicator code, side by side with the chart.
  2. 02Go control planeRoutes each run between the Rust engine and the Python worker.
  3. 03Rust engineOwns candle data, supported indicators, backtest replay, metrics and markers.
  4. 04Chart resultsTrade markers on the chart, plus metrics, a trade list and an equity curve.

When Kshna recognises the pattern, the Python runs on a Rust fast path. Otherwise it runs in a separate Python worker, and every result shows which one ran.

MarketsOpen source

v1indicators

v1indicators is an open-source Python library of technical-analysis indicators. It takes pandas data in and returns pandas data. Its tests reject look-ahead bias and hold the core indicators to plain textbook loops.

  • 182public functions pass the look-ahead test, 547 of 547 cases
  • 1e-9largest gap allowed between about 30 core indicators and textbook loops
  • 5releases on PyPI since Feb 2026

The tests check that the math is right. Nothing in them measures whether the indicators predict anything.

pip install v1indicators

AI agentsOpen source

Vikram

Vikram is an open-source AI engineering team that runs on your own machine, with your own keys. Give it an objective and it plans the work and writes the code. It checks the code with property-based tests, has an independent model review it and hands back a merge-ready branch. Every decision is recorded in a tamper-evident SHA-256 hash chain.

Four rules I work by

  • Build the engine underneath.I build my own engines, such as Kshna's Rust engine, AVSP and v1charts. I would rather own the layer that does the real work.
  • Trust nothing, verify everything.v1indicators is tested for look-ahead bias, and a trading idea has to pass independent checks before it touches real capital.
  • Keep people in charge of AI.Rein runs every mission under a hard budget, holds risky actions for approval and records every call.
  • Run it on your own machine.Vikram and V1Claw run on your own machine with your own keys, and v1media transcribes without uploading anything.
